specification and its Mermaid diagram. Filenames have no date prefix.

- [Stand Tape structure](designs/std-tape.md)
- [A2A Tape storage profile](designs/a2a-tape-storage-profile-design.md)

Project plans live in Obsidian under `anra-studio/tape-go/` and are maintained
through the Obsidian MCP tools. `docs/plans/` is excluded from version control.
The five original documents from that directory were preserved in the vault
with their date prefixes removed; architecture specifications also live here.
